# Мой рацион

Desktop/web-приложение на Python Flet для подсчёта калорийности блюд, ведения базы ингредиентов, истории блюд, статистики и простых дневных рекомендаций.

## Возможности

- регистрация и вход пользователя;
- безопасное хранение паролей через PBKDF2 с солью;
- добавление, редактирование и удаление ингредиентов;
- создание блюд из ингредиентов с автоматическим расчётом калорий;
- история блюд только для текущего пользователя;
- статистика за день, неделю, месяц, год и весь период;
- рекомендация по сумме калорий за текущий день.

## Установка и запуск локально

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
flet run -m app.main
```

SQLite-база по умолчанию создаётся в `data/my_ration.sqlite3`. Путь можно переопределить переменной окружения `APP_DB_PATH`.

## Запуск тестов

```bash
pytest
```

## Docker

Контейнер запускает Flet в web-режиме на порту `8550`.

```bash
docker compose up --build
```

Если контейнер уже собирался до обновления зависимостей, пересоберите образ без кеша:

```bash
docker compose build --no-cache
docker compose up
```

После запуска приложение будет доступно в браузере:

```text
http://localhost:8550
```

Данные SQLite сохраняются в volume `my-ration-data` и не пропадают при пересоздании контейнера.

## Архитектура

- `app/ui` — Flet-экраны, формы, карточки, сообщения пользователю.
- `app/services` — авторизация, расчёт калорий, рекомендации, статистика и бизнес-операции каталога.
- `app/db` — подключение SQLite, модели и репозитории.
- `app/utils` — валидаторы и вспомогательные функции.
- `tests` — минимальные pytest-тесты ключевой логики.
